# Extra groups, in Buildroot's makeusers format (see docs/manual). A line
# whose username is "-" creates only the group.
#
# udev's default rules hand /dev/rtc* to group "clock"; systemd's own
# sysusers would create it at boot, but that needs a writable /etc, which
# the live ISO does not have. Without it udevd logs "Unknown group 'clock'"
# on every boot and the device stays root-only.
-	-1	clock	-1	*	-	-	-	Real-time clock access

# The demo account, and the owner of the graphical session: ade.service
# runs the compositor as this user (through the drop-in in
# rootfs-overlay/etc/systemd/system/ade.service.d, which overrides the
# unit's own "ade" service account) with PAMName=login, so logind opens a
# session on seat0 for it and hands over the DRM and input fds. The
# terminal the session opens is therefore this user's shell in this user's
# home, and sudo asks this user's password.
#
# A member of wheel, which is what both sudo (10-aos-wheel) and polkit's
# default rules treat as administrators. The password is usable only at the
# keyboard: sshd refuses password authentication. An install made with
# "aos-install --release" (./usb.sh --release) deletes this account and
# creates the real one in its place.
admin	1000	admin	1000	=123321	/home/admin	/bin/bash	wheel	Demo account
